# Brand assets

**Empty on purpose.** BetterTago has no mark yet, and two rules constrain what one may look like:

1. **The municipal seal is not free to reuse.** An official seal requires written permission, and using it
   without permission would also falsely imply an endorsement this project does not have.
2. **The palette is deliberately independent** of the municipality's own visual identity. Visual similarity to
   official material reads as affiliation to a resident skimming a page, which is exactly the impression this
   project must never give. See `portal.paletteNote` in `config/lgu.config.json`.

Until a mark exists, the header renders a plain two-tone wordmark from `portal.wordmark` in the config.
